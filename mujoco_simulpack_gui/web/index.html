저장 폴더 선택

Simulpack이 실행 중인 컴퓨터의 폴더입니다.

1. 현재 설정 저장

화면에 입력한 세 영역의 값을 이 컴퓨터에 저장하고, 다음 시뮬레이터 시작에 사용할 설정으로 준비합니다.

확장자는 .yaml로 자동 지정됩니다. 같은 이름이면 기존 파일을 덮어씁니다.

2. 저장된 설정 불러오기

저장된 프로필을 입력칸에 채우고, 다음 시뮬레이터 시작에 사용할 설정으로 준비합니다.

불러오면 현재 입력칸의 값이 선택한 프로필 값으로 바뀝니다.

실행 중 즉시 변경: 각 설정 영역의 Apply 버튼을 사용하세요. Apply는 프로필을 저장하지 않으며, Save / Load는 실행 중인 시뮬레이터에 즉시 적용하지 않습니다.

저장 범위: 세 설정 영역의 입력값. 로봇 현재 자세, 카메라 시점, 플롯 기록, 시편 형상은 포함하지 않습니다.
